## Exercise 2.2

## Theory:
- variables are used to store information of a certain type
- here i need to take name as input and output "Hello "+ <name>
## Code:
```python
name = input("Enter your name")
print("Hello",name)
```

## Concepts Learnt
- you can use `input` to take input from the user
- use `name` variable to store the info
- `print` to print the output


## Exercise 2.3

## Theory:
- we can convert a string taken from the user to a float typed variable
- in this instance we need to output hours times rate to find the pay

## Code:
```python
hrs = float(input("Enter Hours:"))

rate = float(input("Enter rate: "))

print("Pay:",hrs*rate)
```

## Concepts Learnt
- to multiply we use asterisk symbol
- you can multiply any 2 values and then the overall expression's value can be expressed anywhere in the code
